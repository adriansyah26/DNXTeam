# CK Esports — Point Blank Landing Page

Landing page responsif bertema biru muda dan putih, menggunakan logo yang diberikan.

## Menjalankan
1. Ekstrak `pointblank-esport-landing.zip`.
2. Buka folder `pointblank_esport_landing`.
3. Buka `index.html` menggunakan browser modern.

Tidak membutuhkan Node.js, framework, database, atau proses build. Font Google Fonts membutuhkan koneksi internet; jika offline, website memakai font fallback.

## File
- `index.html` — struktur dan konten halaman.
- `style.css` — desain, warna, layout, dan responsivitas.
- `script.js` — menu mobile, tahun otomatis, dan navigasi aktif.
- `assets/logo-pointblank.jpeg` — logo yang diunggah.

## Sebelum dipublikasikan
- Ganti `YOUR NAME` dengan nama roster asli.
- Sesuaikan tanggal dan detail turnamen.
- Ganti tautan Discord/Facebook contoh dengan tautan resmi komunitas.
- Konten dan identitas `CK Esports` dapat diubah di `index.html`.
